# BookingKG — Student Project

This repository contains the BookingKG application layer for the final DevOps
capstone. Students receive React, Node.js and PostgreSQL source code and build
the Docker, Kubernetes, Terraform, AWS and GitHub Actions implementation.

Ready-made infrastructure and CI/CD files are intentionally excluded. Read
[ASSIGNMENT.md](ASSIGNMENT.md) before starting and never commit credentials,
Terraform state, kubeconfig files or private keys.
