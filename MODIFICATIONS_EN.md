# Modifications and Educational Adaptation

**Language:** [Русский](MODIFICATIONS.md) · English

This repository contains the BookingKG travel-booking workload prepared for a
DevOps and cloud-engineering training program.

The student edition includes:

- the BookingKG frontend and REST API workload;
- PostgreSQL initialization and application configuration;
- the student assignment and verifiable acceptance criteria;
- Russian and English educational documentation;
- troubleshooting, assessment, AWS cost, and cleanup guidance.

Ready-made Docker, Kubernetes, Terraform, and CI/CD solutions are intentionally
excluded. The application and educational author is identified in
[NOTICE_EN.md](NOTICE_EN.md). The project is distributed under the MIT License.
